# Family statements kit (draft 0.1)

Open, plain-text tools from Nest Egg Lab for preparing family financial statements by hand or with any AI assistant. Drafts for review: not tested at scale, not reviewed outside, not accounting, tax or legal advice.

| File | What it is |
|---|---|
| `form-2-what-we-own-and-owe.md` | Form 2: one person's statement, with the four tags, the related-party schedule and purpose-built accounts |
| `form-2.schema.json` | The same form as a JSON Schema, for assistants and software that want structured output |
| `instructions-form-2.md` | Instructions a person can paste to their own assistant |
| `test-family-walter/folder/` | Fourteen made-up documents for a made-up family, with gaps, conflicts and one injected instruction planted |
| `test-family-walter/answer-key.md` | What a correct statement contains, and a 40-point score |

Background: [Family financial statements, concepts paper](https://nestegglab.github.io/papers/family-financial-statements.html) and [Brief 1](https://nestegglab.github.io/briefs/personal-financial-statements.html).

Everything in the test folder is fictional. Names, institutions, addresses and numbers are invented.
